# Security Policy

## Reporting Vulnerabilities

**Do NOT open public issues for security vulnerabilities.**

Email [tuziling84@gmail.com](mailto:tuziling84@gmail.com) or use GitHub's private advisory.

## Scope

agent-aura is a client-side WebGL2 library. Typical concerns:

- Shader / GPU resource exhaustion
- Unexpected DOM overlay behavior

We'll credit you in the advisory unless you prefer anonymity.
